# 从这里开始：周三19点前的信贷风控训练

你现在的优势是数学和数据敏感度，短板是离开AI后写代码不够熟练。这个训练包不要求你把所有模型学完。目标是：能独立写常见SQL和pandas，能解释每行代码，能诚实讲清一个已经复现的项目。

## 哪些内容来自哪里

- 岗位主线：你发来的快手信贷JD，重点是准入、授信额度、贷中监控及风险与增长的平衡。
- 面经线索：你本轮粘贴的XHS文字。它们是练习选题依据，不是已核实的快手面试题库，也不保证本次一定考。
- 主项目数据：UCI公开的30,000条台湾历史信用卡客户记录，是真实历史研究数据，半年行为特征预测次月违约。不是快手数据，也不是当前人群。
- 多表练习数据：CreditCheck作者的公开PBIX内嵌合成数据，五张表；没有换成我们生成的数据。主项目与这套练习不拼接。
- 视频、登录、GMV的小表：为手算边界单独编写的教学样例，明确不属于CreditCheck原始数据。

## 一次只做这六步

1. 看题，不看答案。用中文说“我要算什么，最后一行代表什么”。
2. 先拿3到5行样例手算，写出预期结果。
3. 独立写10分钟。卡住就用页面的“复制GPT求助”，只索要一个提示。
4. 执行代码，比较结果。不仅看能否运行，还看行数、金额、分母。
5. 关掉答案，从空白再写一次。
6. 口头解释：为什么这样JOIN？为什么不能直接GROUP BY？空值和重复怎么处理？

每题分四级：0看不懂；1看答案懂；2提示后能写；3无提示能写且讲清边界。面试前核心题要到3级。不要把“答案跑通”记成“自己掌握”。

## Windows开始方法

解压完整ZIP，双击 START.html 阅读本手册。不要在ZIP预览里直接运行。打开解压目录，在地址栏输入cmd回车，或使用Anaconda Prompt并切换到该目录。

```bash
python --version
python -m pip install -r requirements.txt
python run.py
python -m unittest discover -s tests -v
python pandas_lab.py
python interview_cases.py
python algorithms.py
python real_project/run_real.py
```

如果python不存在，使用你已有的Anaconda Prompt，不必新建复杂环境。如果缺pandas，确认安装与运行使用同一个python。run.py只用标准库，pandas训练另需pandas，真实项目还需scikit-learn。代码版没有原始CSV时，分别按README下载两套数据；完整学习ZIP已经带数据。UCI的真实项目从real_project/run_real.py运行，耗时取决于电脑。

练习原项目SQL：编辑sql/exercises/Q02.sql，然后运行 `python practice.py Q02`。练习面经SQL：编辑sql/interview_exercises/I01.sql，然后运行 `python interview_cases.py I01`。练习pandas：编辑pandas_exercises.py，然后运行 `python check_pandas.py P01`。

若SQL报错先看表名、字段名、逗号和GROUP BY。若结果不对，先看一对多关联是否扩行。不要一开始就让GPT整体重写。

## 怎样随时找GPT，又不被答案喂着走

START.html每章有“复制GPT求助”和“打开GPT”按钮。浏览器未允许复制时会显示可手动复制的文本。你将题目和自己的代码粘贴到网页版后再发送。本地页面不会读取账号、自动发消息或上传数据。

第一次新建对话：上传这份学习ZIP或相应章节，并说“我在准备信贷风控面试。请以教练方式，一次只给一处提示，不直接给整题答案。先确认输入、输出、粒度、分母，随后让我手算。”

追问代码时附四样东西：题号、我的代码、报错或实际结果、预期结果。不要只说“不会”。含敏感信息的简历、连接串、真实客户数据不要粘贴；本项目是合成数据也尽量只发5行必要样例。

每天收尾：向GPT报告“今天独立完成哪些题、哪些靠提示、哪一行仍不懂”，让它抽一题变式考你，而不是只给总结。
