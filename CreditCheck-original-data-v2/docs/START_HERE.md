## 口头问答

1. 数据哪里来？作者公开PBIX中提取，作者合成数据，原CSV未公开。
2. 你做了什么？核验数据、独立改写SQL、复现指标、记录差异；完成练习后才能说自己能独立写出。
3. 风险怎么定义？本版按源status=defaulted；与DPD90+、FPD7不能混同。
4. 如何优化策略？信用分分层只是线索，需申请时特征、统一观察窗口、拒绝样本偏差处理、收益约束、OOT与小流量实验。当前数据不支持直接上线判断。
5. 最有价值的发现？README与实际数量不一致；on_time与正dpd并存；口径复核先于报告结论。

## 3分钟陈述提纲

这是我为信贷策略岗位完成的开源数据复现项目，数据由原作者合成。我使用五张业务表分析审批与贷款风险，重点练习了聚合、窗口函数和一对多关联。实际核对发现README的贷款数比模型多1笔，以及on_time存在正DPD。项目让我认识到先确认数据和指标定义，再解释风险结果。代码借助AI整理，我会明确说明自己已经独立复写的SQL，不把练习说成真实实习或上线业绩。
